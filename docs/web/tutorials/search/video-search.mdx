Builds a video search application on V-JEPA (Video Joint Embedding Predictive
Architecture). Generates vector embeddings for video content and uses
[vector search](/search/vector-search) to find visually similar clips -- a
multimodal case where the searchable column is not text.

<Note>
This example is a runnable notebook in the
[vectordb-recipes](https://github.com/lancedb/vectordb-recipes) repository rather than a page here.
</Note>
