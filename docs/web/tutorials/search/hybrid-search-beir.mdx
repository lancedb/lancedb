Uses LanceDB's built-in [hybrid search](/search/hybrid-search), which combines the
strengths of semantic and full-text search. Working against the BEIR dataset, it
shows how searching for both the meaning of a query and the specific keywords in
it produces more relevant results than either alone, and how a
[reranker](/reranking) refines what comes back.

<Note>
This example is a runnable notebook in the
[vectordb-recipes](https://github.com/lancedb/vectordb-recipes) repository rather than a page here.
</Note>
