Covers [multi-vector search](/search/multivector-search) enhanced by XTR
(ConteXtualized Token Retriever): representing complex data with several vectors
for more nuanced meaning, and using XTR to speed retrieval by prioritizing the
most important tokens.

For a comparison of retrieval strategies on a token-level benchmark, see
[Needle in a haystack](/tutorials/search/multivector-needle-in-a-haystack).

[vectordb-recipes](https://github.com/lancedb/vectordb-recipes) repository rather than a page here.
</Note>
