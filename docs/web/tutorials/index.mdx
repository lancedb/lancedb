Every example is one page in the sidebar, grouped by what it builds. The
documentation explains how a feature works; these show it doing something.

Examples marked as notebooks live in the
[vectordb-recipes](https://github.com/lancedb/vectordb-recipes) repository and
are runnable in Colab; the rest are written up here.

## The features these use {#read-the-docs}

| Feature | What it covers |
|:--------|:------------|
| [Vector search](/search/vector-search) | Similarity search, distance metrics, and tuning it. |
| [Full-text search](/search/full-text-search) | Keyword search over text columns. |
| [Hybrid search](/search/hybrid-search) | Keyword and vector search combined. |
| [Multi-vector search](/search/multivector-search) | Several embeddings per document. |
| [Reranking](/reranking) | Reordering results to improve the top-k. |
| [Feature engineering](/feature-engineering) | Deriving columns and tables from data already stored. |
| [Materialized views](/management/materialized-view) | A table defined by a query, refreshed incrementally. |
| [Training](/training) | Reading a table into a data loader. |
