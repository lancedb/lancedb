[Mastra](https://mastra.ai) is an open-source TypeScript framework for building AI agents, workflows, and retrieval-augmented generation (RAG) pipelines. Its official `@mastra/lance` package connects Mastra to LanceDB Embedded on local disk with no separate database server.

## Installation {#installation}

`@mastra/lance` requires Node.js 22.13.0 or later and depends on `@mastra/core`. Install both packages:

<CodeGroup>
```bash Bash icon="terminal"
npm install @mastra/lance @mastra/core
```
</CodeGroup>

Installing `@mastra/lance` also installs `@lancedb/lancedb` and the matching native binary for your platform.

## Native vector index {#native-vector-index}

The first `createIndex()` call initializes an empty LanceDB table without building a native vector index. When `tableName` is omitted, `indexName` sets the table name and `vector` is the vector column. Queries work on small tables immediately through flat scan.

To build a native [LanceDB vector index](/indexing/vector-index) when extending the quickstart, call `createIndex()` again after upserting at least 256 rows and before `store.close()`:

<CodeBlock filename="TypeScript" language="TypeScript" icon="square-js">
  {TsFrameworksMastraNativeIndex}
</CodeBlock>

Supported `indexConfig.type` values include `"ivfflat"`, `"ivfpq"`, and the default HNSW PQ index.

## Application storage and references {#application-storage-and-references}

`@mastra/lance` also exports `LanceStorage` for Mastra agent memory and workflow state. The published `LanceStorage.create(id, name, uri)` factory takes three required arguments (`id`, `name`, and `uri`). See the [released `LanceStorage.create` implementation](https://github.com/mastra-ai/mastra/blob/d60ba71be015e2acbdc303208a14563902fb1f39/stores/lance/src/storage/index.ts#L78-L119) for the current signature if you encounter older two-argument examples.
