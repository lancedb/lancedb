## Lance format overview {#standard}

[Lance](https://lance.org/) is an open-source, columnar format designed for
multimodal AI. It defines how data is stored and organized into versioned tables.

<span id="embedded" />
<span id="enterprise" />

LanceDB Embedded and LanceDB Enterprise both use Lance as their storage foundation.
The format is developed as an independent open-source project, with its own
specification and tools.

## Multimodal data {#storage}

A Lance table can hold images, video, audio, text, embeddings and structured
metadata together. For example, a video dataset can keep each clip alongside
its caption, labels and embeddings, so applications can search and work with
those fields together.

## Data access, versioning and column updates {#capabilities}

- **Efficient data access.** Read individual rows for retrieval and training,
  or scan columns for analytics.
- **Versioned data.** Read an earlier table version to reproduce an experiment
  or inspect previous results, while that version is retained.
- **Independent column updates.** Add embeddings or other derived features
  without rewriting the existing image, video or text columns.
