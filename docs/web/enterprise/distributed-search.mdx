Distributed search spreads index execution, table-data reads, and caching across
multiple serving machines in LanceDB Enterprise. Query nodes plan queries and
combine results. Plan executors cache index structures and table data and execute
the remote work -- see [Data Page Cache](/enterprise/data-page-cache) and
[Tiered Index Cache](/enterprise/tiered-index-cache) for how each cache works.
See [Architecture](/index#architecture).
