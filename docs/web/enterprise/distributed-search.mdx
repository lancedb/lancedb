Distributed search spreads index execution, table-data reads, and caching across
multiple serving machines in LanceDB Enterprise. Query nodes plan queries and
combine results. Executors cache index structures and table data and execute
the distributed work. See [Enterprise architecture](/enterprise/architecture).

## Embedded search {#embedded-search}

LanceDB Embedded runs inside your application process. It searches indexes and reads
table data using that process's resources, including its index cache. Reading a
table from object storage does not by itself distribute query execution across
machines.
