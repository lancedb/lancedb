Distributed SQL places each query rather than always fanning it out: LanceDB
Enterprise runs a query inline on the query-serving fleet like any other
search, or starts a dedicated SQL job worker for it, and that choice does not
change the query's job-backed identity. Query nodes host the Flight SQL
endpoint; plan executors execute the sub-plans they dispatch. See
[Architecture](/index#architecture).

## Embedded SQL {#embedded-sql}

LanceDB Embedded has no SQL engine or Flight SQL endpoint, so there is no
query to place on a fleet. See [SQL](/basics/sql) for where SQL runs today.
