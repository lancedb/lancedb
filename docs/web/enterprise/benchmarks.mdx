<Badge color="red">Enterprise</Badge>

This page describes a LanceDB Enterprise capability. The embedded form
of LanceDB has no server to provide it -- see
[Architecture](/architecture) for what differs between the two.

Benchmark results are specific to a deployment's shape -- cluster size, storage
class, dataset -- so they are published with LanceDB Enterprise.

For tuning your own workload rather than comparing published numbers, see
[Query plans](/search/explain) and the performance notes on
[Search](/search#performance) and [Insert](/ingestion/insert#performance).
