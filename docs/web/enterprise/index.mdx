<Badge color="red">Enterprise</Badge>

This page describes a LanceDB Enterprise capability. The embedded form
of LanceDB has no server to provide it. See
[Architecture](/index#architecture) for what differs between the two.

LanceDB Enterprise runs the lakehouse as a service: a control plane for
configuration, identity and policy; a data plane serving reads and writes; and
indexers building indexes and compacting outside the request path.

What it adds over the embedded form:

| | |
| --- | --- |
| [SQL](/sql) | an Arrow Flight SQL endpoint |
| [Jobs](/basics/jobs) | server-side work with ids, status and events |
| [Authorization](/governance/authorization) | per-object grants |
| Scale | a cluster rather than your process |

## Getting a deployment {#deployment}

Deployment is specific to your cloud and account, so the procedure is
published with LanceDB Enterprise rather than here.
[Contact us](https://www.lancedb.com/contact) to get started; see the
[Kubernetes deployment guide](/enterprise/deployment/kubernetes) for a worked example.
Embedded LanceDB has nothing to deploy: it is a library your process links
against -- see [LanceDB Embedded](/#1-lancedb-oss).
