Distributed column refresh plans a computed column's or materialized view's
stale rows into claimable units -- grouped by which fragments still need the
column computed -- then fans the units out across job workers in LanceDB
Enterprise. Each unit runs the bound Function, including GPU-backed and
containerized Functions, and workers commit finished columns together
through the job registry. See [Architecture](/index#architecture).
