<Badge color="red">Enterprise</Badge>

This page describes a LanceDB Enterprise capability. The embedded form
of LanceDB has no server to provide it -- see
[Architecture](/architecture) for what differs between the two.

Compliance posture -- certifications, data residency, encryption at rest and in
transit, audit logging -- is a property of a deployment, so it is documented
with LanceDB Enterprise.

For embedded LanceDB, these are properties of the object store you point it at
and the process you run it in; LanceDB adds no layer of its own.
