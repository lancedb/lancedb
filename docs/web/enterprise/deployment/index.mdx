<Badge color="red">Enterprise</Badge>

This page describes a LanceDB Enterprise capability. The embedded form
of LanceDB has no server to provide it -- see
[Architecture](/architecture) for what differs between the two.

Deployment is specific to your cloud and account, so the procedure is published
with LanceDB Enterprise. [Contact us](mailto:contact@lancedb.com) to get
started.

Embedded LanceDB has nothing to deploy -- it is a library your process links
against. See [Architecture](/architecture#embedded).
