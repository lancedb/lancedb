<Badge color="red">Enterprise</Badge> [SQL runs on a deployment.](/sql)

```sql
INSERT INTO documents (id, title) VALUES (1, 'Merlin'), (2, 'Arthur')

INSERT INTO archive SELECT * FROM documents WHERE created_at < '2026-01-01'
```

`INSERT ... SELECT` is the form worth knowing: it moves rows between tables
server-side, without a round trip through your process.

Commits a new table version, so [versioning](/management/table#versioning) and
the [write guarantees](/basics/guarantees#writes) apply -- including that the
version advances even when the statement affects zero rows.
