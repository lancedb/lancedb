A LanceDB extension with no DataFusion equivalent.

```sql
REFRESH MATERIALIZED VIEW <name>
```

```sql
REFRESH MATERIALIZED VIEW chunks
```

A refresh updates the view's stored result. Refresh views in dependency order,
starting with their source views.

<Note>
Some older server versions accepted `WITH (full = true)` and `CASCADE`.
Those options are not accepted by the SQL implementation described here.
Use the basic statement above; do not assume that the options accepted by a
local SDK's `refresh()` method are also SQL options.
</Note>

## Watching a refresh {#watching}

A refresh submits work that outlives the call. Track it with
[`SHOW JOBS`](/sql/ddl/job#show), and diagnose failures with
[`SHOW ERRORS`](/sql/ddl/job#errors).
