## LanceDB OSS {#oss}

For a quick question, the
[Discord community](https://discord.gg/AUEWnJ7Txb) has channels for
Python, TypeScript and Rust where you can ask the community for help.

Use GitHub for discussions and issues that others can search and follow:

| | |
| --- | --- |
| [GitHub Discussions](https://github.com/lancedb/lancedb/discussions) | Open-ended questions, design questions, "what's the right way to do X" |
| [GitHub Issues](https://github.com/lancedb/lancedb/issues) | A specific bug, or a feature request |

## LanceDB Enterprise {#enterprise}

<Badge color="red">Enterprise</Badge> Contact your support team directly at
[support@lancedb.com](mailto:support@lancedb.com) for dedicated assistance.

## What to include {#what-to-include}

A faster answer usually depends on the same handful of details:

| | |
| --- | --- |
| SDK and version | `lancedb.__version__` (Python), `package.json` (TypeScript), the crate version (Rust) |
| Connection type | embedded path, or a `db://` deployment |
| The exact error | full traceback or error message, not a paraphrase |
| A minimal repro | the smallest table schema and call that reproduces it |
