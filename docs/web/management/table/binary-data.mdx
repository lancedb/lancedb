Use this guide when queries should return file contents as raw bytes.
For payloads you want to fetch separately, use [Blob columns](/management/table/multimodal).

## Store binary data {#multimodal-store-binary-data}

Use a `binary` column when the query should return the raw bytes. Declare it as `pa.binary()` in Python, `Binary` in TypeScript, and `DataType::Binary` in Rust.

## Other modalities {#multimodal-other-modalities}

For PDFs, audio recordings, and other files, keep searchable fields in separate
columns so you can filter rows before fetching blob bytes.
