# lancedb-test-fixtures

Immutable fixtures shared by LanceDB clients and downstream consumers.

`lancedb_test_fixtures::v1::FUNCTION_ARROW_TYPES_JSON` is the exact UTF-8
content of the Function Arrow type golden. Parsing and interpreting the fixture
stays with the consumer.

Use this crate as a dev-dependency pinned to the same Git revision or published
release as `lancedb`.
