# **专为 AI 打造的多模态湖仓系统 (The Multimodal Lakehouse for AI)**

[**如何安装**](#如何安装-how-to-install) ✦ [**详细官方文档**](https://docs.lancedb.com) ✦ [**教程与实战食谱**](https://github.com/lancedb/vectordb-recipes/tree/main) ✦ [**贡献者名单**](#贡献者-contributors)

**面向 AI/ML 应用的终极多模态数据平台。**

LanceDB 专为快速、高可扩展且生产就绪的向量检索打造。它深度构建于 Lance 列式存储格式之上，能够轻松存储、索引与检索 PB 级多模态数据与海量向量。
LanceDB 是开发者构建、训练和分析其 AI 工作负载的核心中枢。

## **核心特性 (Key Features)**：

- **极速向量检索**：搭载前沿向量索引，可在毫秒级延迟下完成数十亿向量的检索。
- **全功能综合检索**：全面支持向量相似度检索、全文检索（FTS）以及标准 SQL 查询。
- **原生多模态支持**：统一存储、查询和过滤向量、元数据以及多模态原始数据（文本、图像、视频、点云等）。
- **企业级高阶特性**：零拷贝数据读取、自动化版本控制、无需额外基础设施即可实现数据版本管理，支持 GPU 构建向量索引。

### **产品矩阵 (Products)**：
- **LanceDB 嵌入式版本（开源）**：100% 开源，直接嵌入宿主应用程序进程中运行；数据可存放于本地磁盘或云端对象存储，彻底告别厂商锁定。
- **LanceDB 企业版 (Enterprise)**：专为生产规模打造的分布式检索、索引构建与自动化运维系统，同时提供完整的数据主权与企业级安全合规。

### **生态体系 (Ecosystem)**：
- **列式存储底座**：基于现代 Lance 列式存储格式构建，兼具高压缩比与极速分析能力。
- **多语言无缝集成**：提供 Python、Node.js、Rust 原生 SDK 以及标准 REST API 接口。
- **丰富的框架生态**：与 [**LangChain** 🦜️🔗](https://docs.lancedb.com/integrations/ai/langchain)、[**LlamaIndex** 🦙](https://docs.lancedb.com/integrations/ai/llamaIndex)、Apache Arrow、Pandas、Polars、DuckDB 深度集成，更多生态连接持续拓展中。
